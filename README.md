# Workout Tracker

An Android app for logging workouts. This was one of my first Android projects - just the basics: log an exercise and see your history.

## What it does
- Add a workout (exercise name, sets, reps, weight, date)
- View full workout history from the local database
- All data stays on the device (SQLite)

## How to run
Open the project in Android Studio and run it on an emulator or a physical device. Needs minSdk 24.

## Tech
Java, Android SDK, SQLite (SQLiteOpenHelper)
